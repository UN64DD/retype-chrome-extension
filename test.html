Use this page to test the Retype Chrome extension (Phase 1). Each field below exercises one supported editable element type.

How to test

  1. Load the retype-extension folder as an unpacked extension (see README).
  2. Click inside one of the fields above so it is focused.
  3. Click the Retype icon in the Chrome toolbar to open the side panel (it stays open when you click the page).
  4. Paste or type some text, pick a typing delay, and press Start.
  5. Watch the text appear one character at a time; check the status and progress in the side panel.
  6. Try Pause (typing should freeze, then resume from the same character), Stop (typing halts; a new Start begins from the start), and Clear.
  7. Try Start without focusing a field first - you should see a helpful error.

Local files and Chrome's extension security

If you opened this page as a local file (file:///.../test.html), Chrome blocks extensions from reading it by default. Either enable Allow access to file URLs on the extension's details page (chrome://extensions/ → Retype → Details), or serve this folder over a local HTTP server, which needs no extra permission: 

python3 -m http.server 8000

Then open:

http://localhost:8000/test.html

Suggested test cases

  1. Type Hello world! into the textarea - expect H → He → Hel → ... → Hello world!
  2. Type multiple lines - newlines must be preserved in the textarea.
  3. Pause mid-typing, then resume - it must continue at the same character.
  4. Stop mid-typing - typing must halt completely.
  5. Start with no focused field - expect "No editable field detected."
  6. Repeat for the textarea, the text input, and the contenteditable div.
